# Metroid Prime Remastered Recomp

A native Windows x64 port of Metroid Prime Remastered, built by statically recompiling the Nintendo Switch release (v1.0.0). It is built on the [nxrecomp](https://github.com/drakolordx7/nxrecomp) toolkit, which is included as the `base` submodule.

Planned PC features:

- any resolution and aspect ratio, ultrawide included, with a correct HUD
- high refresh rates (120, 144, 240 Hz and uncapped) with game speed and physics unchanged
- raw mouse aim, full keyboard and mouse controls, and rebinding
- FOV, quality and latency options, plus HDR
- optional FSR 3.1 upscaling and frame generation, and DLSS or XeSS if you supply the DLLs

You need your own copy of the game and your own console keys. This repository contains no game code, assets or keys.

Status: early development. `docs/PLAN.md` has the plan.
