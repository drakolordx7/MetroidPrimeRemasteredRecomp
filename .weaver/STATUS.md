# Status: Metroid Prime Remastered PC recomp

## Where it stands
The real game runs natively on Windows from the title screen through New Game into the Frigate Orpheon (opening cutscene, landing, hangar with HUD, lighting, fog, bloom, audio, movies). Both GitHub repos are public: github.com/drakolordx7/MetroidPrimeRemasteredRecomp and github.com/drakolordx7/nxrecomp.

## Done (merged on main)
- Recompiler (`recomp/`): difftest 565,061/565,061, mutation 22/22, e2e 30/30, hooks; oracles locked. Lifts and compiles main/sdk/subsdk0/rtld (138,502 functions) in about 2 minutes. Hook sites in `recomp/games/mpr/main.sites`.
- Offline tools (`tools/`): shader harness (Ryujinx), ASTC→BC7 (normal maps fixed, 4,413/4,413 pass), tiling, setup tool (NSP/XCI/NSZ + keys, version check, ~5 min setup), release builder (refuses game data, 286 MiB zip, clean-room install reaches the title), test tooling (deterministic mode, state hash, input replay, script runner, probes, comparators, Eden references).
- Runtime (`runtime/` main): ABI 3, C++ exceptions, Horizon services, NVN on Vulkan (struct sizes from the game, storage images, sparse textures, occlusion, transform feedback), shader cache (67,506 blocks), movies on Media Foundation, audio paced by the sink, window + controllers + keyboard/mouse bindings + mouse aim + F1 settings, real-time timestep (60/120/144/240 run at real speed), display options (resolution, Hor+ ultrawide, FOV, AF, LOD bias, post toggles, dynamic resolution off), perf fixes (title 140 fps at a 144 cap), pipeline prewarm, HDR10/scRGB, Reflex, frames-ahead pacing, FSR 1, scene scale. S18: frame limiter moved to the frame boundary (input to present 49 → 9 ms p50 at a 60 cap), pool imports through small heap views (63 → 0.19 ms each), unlinked programs no longer rebuilt every bind. S19: button prompts fixed (small-texture block height) with Switch/Xbox/PlayStation/keyboard styles switchable live, setup tool writes BC5/RGBA8 entries (encoder rev 3, 4,369 entries in 3.5 min), null-image barrier and image-layout validation errors fixed, shader pack 13,020 entries, release licences added. S20: starvation guard ends the load hangs. S21: background texture prepare (hitches over 50 ms 16 → 5 per route run), movie preroll/async close (main-thread movie stalls 14 → 0-1), Reflex gets the frame cap, vsync cap 0.05% under refresh. S22: no VC++ redistributable needed (static runtime, release import audit), all 173 config keys documented, keyboard beam keys 1-4 / visor keys 5-8 / wheel cycles beams, physics probe fixed (the "4% slow walk" was a probe error). S25: playable from New Game through the first Frigate force fields and on Tallon IV/Chozo Ruins (Main Plaza); mouse-aim write fix took gameplay frames from 100-200 ms to ~10 ms; save/load, pause, map, morph ball, charge, missiles on keyboard/mouse and pad checked; live test mode (`[test] live`, `.weaver/live.py`). Gameplay runs need `NXRT_NVN_SHADER_CACHE=D:\AI\Active\Metroid-Prime\work\shader_cache\spirv`.

## Shortcomings to fix
- High refresh: physics matches within 0.5% at 60-240 steps (S22, S25 fixed the 240-step jump stall); morph ball +1-2% at 120-240 unconfirmed (S26); real-time stepping with a frame cap not yet checked in an unscripted window run.
- Timing-sensitive tests (kernel_threads, svc_info, gfx_nvn_scene_stress, watchdog, gfx_pacing) can fail under heavy machine load and pass alone.
- New dev docs (S8-S18) have not had the plain-language pass yet.
